# Contributing

Open a GitHub pull request against `main` with a focused change and a short
description of the behavior it changes. Include a test or an acceptance journey
when the change affects behavior. For browser-visible interactions, cover the
complete action and visible result rather than only a rendered page.

The maintainer reviews pull requests here, applies accepted changes to the
authoritative Framagit repository, and lets the public mirror update afterward.
Because the two repositories have different histories, a merged Framagit change
may appear in GitHub as a mirror sync commit. The maintainer will close the
pull request with a link to the corresponding change. Do not merge a pull
request directly into GitHub `main`.

The Framagit repository contains private review evidence that is deliberately
excluded from this public code mirror. Please do not include private user data,
credentials, or production review artifacts in a pull request.

# Public mirror guidance

This GitHub repository is a code mirror. Framagit is the authoritative source;
see [CONTRIBUTING.md](CONTRIBUTING.md) before proposing changes. Do not merge
directly into GitHub `main`.

Keep private review evidence, credentials, and production data out of this
repository. Browser-visible changes need an acceptance journey that performs
the action and checks the visible result. Follow the
[acceptance contract](docs/acceptance-contract.md) for scenario design and
evidence isolation.

Use Semantic Versioning for releases. Do not add `Co-Authored-By:` or generated
by-agent trailers to commits.
